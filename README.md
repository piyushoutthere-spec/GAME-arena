# Game Arena
The Arena contains 3 small games 2048, Maze and Tic-Tac-Toe.
## Description 
The Game Arena is built using HTML , CSS and JavaScript. The game contains 3 small games which we all know. 2048 is a game where you slide the tiles to add up number 
and get more and more Score. Maze is a game where you will find the route to get escaped in from a starting point. Tic Tac Toe is connecting the same character 3 in 
row or column or diagonal, i have put Fire and Ice instead of X and O.

- NOTE: I have not added the bot based playing where you play with a bot.
